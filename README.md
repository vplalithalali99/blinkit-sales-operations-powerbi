# Blinkit Sales & Operations Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze Blinkit's sales performance, customer segments, product performance, and delivery operations.

---

## 📊 Project Overview

This project transforms Blinkit sales and operational data into an interactive business intelligence dashboard.

The dashboard provides a consolidated view of:

- Sales performance
- Order and item metrics
- Customer segments
- Product revenue performance
- Delivery status
- Monthly revenue trends
- Category-wise revenue

The goal is to convert raw transactional data into meaningful business insights that can support data-driven decision-making.

---

## 🎯 Business Objective

The objective of this project is to analyze sales, customer, product, and delivery data and provide an interactive dashboard for monitoring business performance.

The dashboard helps answer questions such as:

- How is revenue changing over time?
- Which product categories generate the most revenue?
- Which products are the top revenue contributors?
- Which customer segments contribute the most revenue?
- What percentage of orders are delivered on time?
- How are orders distributed across delivery statuses?
- Which payment methods are most commonly used?

## 📊 Dashboard Features

### 1. Executive Dashboard

The Executive Dashboard provides a high-level overview of sales and operational performance.

Key visuals include:

- Total Revenue
- Total Orders
- Total Items
- Total Customers
- Average Order Value
- On-Time Delivery %
- Revenue by Month
- Revenue by Category
- Top 10 Products by Revenue
- Revenue by Customer Segment
- Orders by Delivery Status

### Interactive Filters

Users can dynamically filter the dashboard using:

- Order Date
- Customer Segment
- Delivery Status

---

### 2. Customer Insights

The Customer Insights page focuses on customer behavior and revenue contribution.

Key analysis includes:

- Customers by Segment
- Revenue by Customer Segment
- Orders by Payment Method
- Top 10 Customers by Revenue
- Customer Segment filtering
- Order Date filtering

---

## 🔄 Interactive Navigation

The report includes a Power BI page navigator allowing users to move between:

- Executive Dashboard
- Customer Insights

This provides a seamless multi-page dashboard experience.

---

## 🧮 DAX Measures

DAX measures were created to calculate key business metrics dynamically.

Examples include:

- Total Revenue
- Total Orders
- Total Items
- Total Customers
- Average Order Value
- On-Time Deliveries
- On-Time Delivery %
- Orders per Customer

These measures allow dashboard visuals and KPIs to respond dynamically to user selections.

---

## 🔗 Data Modeling

The project uses a relational Power BI data model connecting relevant transactional, product, customer, and operational datasets.

The data model was designed to support:

- Relationship-based analysis
- Dynamic filtering
- Aggregation across multiple datasets
- Interactive dashboard reporting

Power Query was used for data preparation and transformation before building the analytical model.
